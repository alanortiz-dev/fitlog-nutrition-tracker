# FitLog

Mobile-first nutrition tracking MVP focused on the Today screen.

## What it includes

- Daily food logging centered on Today
- Add food by search, barcode mock flow, or custom food creation
- Mock auth, onboarding, history, and profile flows
- Premium wellness-style mobile UI foundation

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run build
npm run test
```

## Notes

This repository is currently an MVP foundation intended for portfolio presentation and iterative product development.
